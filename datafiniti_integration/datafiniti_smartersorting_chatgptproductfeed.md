# ai-agentic-retailing-benchmark

Minimal runner for executing **agentic retailing benchmark** test scenarios against multiple AI platforms (e.g. ChatGPT, Gemini, Claude, Copilot). The benchmark loads a set of multi-step shopping scenarios, executes them against selected platforms, and writes a timestamped report.

The project is intentionally dependency-free: it uses the Python 3.9+ standard library for platform integrations and test orchestration. A Dockerfile is provided for convenience.

---

## Requirements

- Python 3.9+
- No external dependencies required for core benchmark execution
- Optional (Gemini support only):
  ```bash
  pip install -U google-genai
  ```

---

## Running the Benchmark

Run all scenarios using the default dataset:

```bash
python main.py --setting retailing-benchmark --env .env
```

Key CLI flags:

- `--setting` – Dataset configuration key
- `--env` – Path to `.env` file with API keys
- `--platform` – Comma-separated list (e.g. `CHATGPT,GEMINI`)
- `--exclude-platform` – Skip specific platforms
- `--scenario-start`, `--scenario-end` – Run a subset of scenarios

Reports are written to:

```
reports/test_report_<timestamp>.xlsx
```

## Datafiniti → SmarterSorting → ChatGPT Product Feed

This repository includes a **reference integration** for using **Datafiniti product data** to:

1. Test agentic shopping benchmarks with real-world catalogs
2. Convert product data into the **official ChatGPT commerce product feed format**

### High-level pipeline

```
Datafiniti Product API
        ↓
(optional) SmarterSorting Enrichment
        ↓
ChatGPT Commerce Product Feed
        ↓
Agentic Shopping Benchmark
```

---

## Datafiniti Product Data

Datafiniti provides large-scale product catalogs via a boolean search API that supports both preview searches and bulk downloads.

### Preview search (up to 10 records)

```http
POST https://api.datafiniti.co/v4/products/search
Authorization: Bearer <DATAFINITI_API_KEY>
```

```json
{
  "query": "categories:shoes AND categories:women",
  "num_records": 10,
  "format": "JSON"
}
```

### Bulk download (full dataset)

```json
{
  "query": "categories:shoes AND categories:women",
  "format": "JSON",
  "download": true
}
```

The API returns a download job ID. The job is polled until completion, at which point one or more result files (JSONL or CSV) are provided.

## SmarterSorting Enrichment (Optional)

Products can optionally be enriched using the **public SmarterSorting enrichment API**, which normalizes and augments product attributes using UPC/GTIN identifiers.

### Endpoint

```
POST /api/enrich_public
```

### Example request

```json
{
  "upc": "733739017154",
  "product_name": "NOW Black Currant Oil 500mg"
}
```

### Authentication

```
Authorization: Bearer <SMARTERSORTING_API_KEY>
```

The enrichment response may include:

- Canonical brand normalization
- Enriched product descriptions
- Scope and eligibility flags
- Structured attribute extraction

Enrichment is optional and safely skipped if unavailable or if a product lacks a valid UPC.

## ChatGPT Commerce Product Feed

The output generated by this integration conforms to the official **OpenAI / ChatGPT commerce product feed specification**.

### Required fields

- `is_eligible_search`
- `is_eligible_checkout`

### Core identifiers

- `item_id`
- `title`
- `description`
- `url`

### Optional commerce attributes

- `gtin`, `mpn`, `sku`
- `brand`
- `price`, `currency`
- `image_url`, `additional_image_urls`
- `product_category`, `color`, `size`, `material`

The integration attempts to populate **all possible fields** when data is available, while remaining tolerant of missing or sparse records.

## CLI: Datafiniti → OpenAI Feed Converter

Script location:

```
datafiniti_integration/main.py
```

The script reads API keys from a `.env` file by default. Use `--env` to point
to a different file if needed.

### Basic usage

```bash
python datafiniti_integration/main.py \
  --query "categories:shoes AND categories:women" \
  --num-records 50 \
  --output-file products.jsonl
```

### With SmarterSorting enrichment enabled

```bash
python datafiniti_integration/main.py \
  --enrich \
  --query "gtins:*" \
  --seller-name YOUR_BRAND \
  --output-file enriched_products.jsonl.gz
```

### Supported output formats

- `.jsonl`
- `.csv`
- Optional gzip compression via `.gz`

## Using Your Catalog in the Benchmark

1. Generate a product feed using the Datafiniti integration script
2. Convert or map the feed to `product_ground_truth.xlsx`
3. Register a new dataset in `main.py`:

```python
DATASET_CONFIGS["my-datafiniti"] = {
    "tests_xlsx": "my-datafiniti/shopping_paper_tests.xlsx",
    "ground_truth_xlsx": "my-datafiniti/product_ground_truth.xlsx",
    "scoring_prompt": "retailing-benchmark/scoring_prompt.txt",
}
```

4. Run the benchmark:

```bash
python main.py --setting my-datafiniti --env .env --platform CHATGPT
```
