# Electronics Deep Dive Dataset

This dataset provides an in-depth analysis of AI agent performance on electronics products.

## Purpose
Focus on a single product category (electronics) to understand:
- Detailed attribute handling (technical specifications)
- Complex product comparisons
- Category-specific regulatory requirements
- Technical jargon understanding

## Dataset Structure
- `electronics_tests.xlsx`: Electronics-focused test scenarios
- `electronics_ground_truth.xlsx`: Ground truth for electronics products
- `electronics_scoring_prompt.txt`: Electronics-specific scoring criteria

## Example Test Scenarios
1. Laptop specifications comparison
2. Smartphone feature matching
3. TV resolution and features
4. Audio equipment technical specs
5. Gaming console comparison
